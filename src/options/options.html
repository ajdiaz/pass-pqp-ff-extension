pass-pqp options

Native host configuration

Leave a field empty to fall back to the native host defaults (environment variables or built-in defaults).

Path to the pass-pqp wrapper or to the raw pqp CLI. The host probes the binary and uses show for the wrapper or decrypt for the raw CLI. Defaults to pass-pqp in your PATH.

Path to the raw pqp CLI. Only needed when pass-pqp binary path points at the pass-pqp wrapper, so the wrapper can find pqp (the browser environment usually does not have it on PATH). Leave empty to fall back to pqp on PATH.

Location of the password store. Defaults to $PASSWORD_STORE_DIR or ~/.password-store.

Passes --no-passphrase to pqp decryption. Requires keys created with pqp gen-key --no-passphrase. When disabled, a password tool below becomes mandatory.

External passphrase prompt tool passed as --password-tool to pqp decryption. Only used when Decrypt without a passphrase prompt is off. Either no-passphrase or a password tool is mandatory. Tools whose name contains pinentry use the Assuan protocol; others are called as <tool> <prompt> reading the passphrase from stdout.
